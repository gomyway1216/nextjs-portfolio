# v8教師データを学習へ渡す最短の橋

2026年7月19日時点で、v8教師生成はまだ24,000親の途中です。100・500親の節目は完了し、500親では499親から学習候補を生成し、1親は探索タイムアウトとしてラベルを一切残さず隔離しました。確認時点の進捗は690親です。したがって、評価関数が強くなった、学習が終わった、という状態ではありません。

今回追加したのは、教師生成が終わった直後に余計な作業を挟まず、正しいデータだけを3-seed学習へ渡す橋です。棋力に直接効くのは教師ラベルと再学習ですが、途中ファイルや対応の崩れた行を学習すると、その計算時間を丸ごと失い、評価関数を再び悪化させます。その一度だけの入口検査に範囲を絞りました。

## 何を確認するか

TypeScriptの検証器が、認証済みの元行を再解釈し、最終結果、manifest、staged result、100・500の節目、全work行、親ごとの完了行、学習行を一つの連鎖として確認します。workは逐次読みするため、24,000親分を同時にメモリへ載せません。

特に、各親は「学習グループを出した」「合法手が2未満で強制スキップした」「探索タイムアウトでラベルなし隔離した」のどれか一つだけです。500親で観測したタイムアウト1件もこの集計に入り、別の理由へ付け替えたり、部分ラベルを混ぜたりすると停止します。

成功時にPythonへ渡すのは、親数、採用数、理由別スキップ数、学習行数だけです。親ID、局面、内部ファイルのハッシュは公開planへ出しません。v2 planは外側の最終結果だけを固定し、実学習の直前に、その結果が束縛する全内部ファイルをもう一度読み直します。

## いま通った検証

- TypeScript全体の型検査: PASS
- 小型の実連鎖テスト: 2件 PASS（最大2 workers）
- 既存教師生成の共有処理回帰: 2件 PASS（通常継続とtimeout隔離）
- Pythonの学習plan・実行橋・選抜前ゲート: 89件 PASS
- CLIのpath上書き拒否と安全な失敗出力: PASS

正式教師が動いている間は、CPUを奪う全テストや重いbenchmarkは実行していません。この橋自身のnetwork、AWS、Firebase / GCP、Vercel利用は0で、ライブ重み変更も0です。

## 残っている棋力工程

順序は、24,000親の教師完了、実データでの検証、v2 planのレビュー、seed 42・43・44の再学習、候補選抜、正式A/B、外部校正、最後に安全なライブ切替です。現在は最初の教師生成中なので、まだ高段や棋力向上を主張できません。

機械可読の記録は [evidence JSON](./data/floodgate-strength-first-v8-downstream-provenance-2026-07-19.json) にあります。
