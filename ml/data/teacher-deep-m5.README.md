# teacher-deep-m5.jsonl — 深いラベル教師データ (M5 Pro 生成分)

将棋 NNUE 蒸留学習用の「中盤重視・深いラベル」教師データ。2台目マシン **M5 Pro (18コア)** で
並列生成し、母艦 M4 が回収してマージする分担のうちの M5 生成分。

- 生成日: 2026-07-08〜09 (JST)
- ブランチ: `deep-labels-m5`
- 出力: `ml/data/teacher-deep-m5.jsonl` (319,517 局面, 約41MB)

## レコード形式 (既存教師 jsonl と同一 schema)

```json
{"sfen":"<board> <teban> <hand> <movecount>","cp":<int>,"ply":<int>,"bestmove":"<usi>","depth":16}
```

- `cp`: **手番側視点**の評価値 (centipawn)。詰みは `±(30000 - 詰み手数)` に写像。
- `depth`: 全レコード 16 (やねうら王 `go depth 16`)。
- 詰み局面には追加で `"mate":<int>` フィールドが付く (10,685 局面)。
- 重複排除キーは手数を除いた SFEN (`board teban hand`)。ファイル内は dedup 済み。

## 生成条件

- **エンジン**: やねうら王 (NNUE), 評価関数 Háo `nn.bin` (64MB)。`FV_SCALE=20`, `Threads=1`, 定跡OFF。
- **ラベリング深さ**: `--depth 16` (固定深さ探索、手番側 cp)。
- **局面生成**: 自作エンジン ShogiAIImprovedV20 の自己対戦。着手選択は本番 WASM エンジン
  (`--wasm`, 定跡→WASM探索) + ε=0.2 のランダム分岐で多様化。
- **中盤重視**: `--min-ply 20 --max-ply 60` (王手中の局面は除外)。
- **分布バランス**: `--balance` で `|cp|>1200` の大差局面を採択率 30% に間引き、互角圏の比率を確保。
- **マシン構成**: 生成ドライバ 3 本 × `--engines 5` = やねうら王 15 プロセス並列。`caffeinate -i` 配下。
- 実行: `YANE_BIN`/`YANE_EVAL_DIR` でエンジン実体を指定し `node -r tsx/cjs ml/generate-teacher.ts`。

## 母艦 M4 での回収・マージ

`git pull` 後、`ml/data/teacher-deep-m5.jsonl` を既存教師データに連結。
`generate-teacher.ts` の再開ロジックは SFEN キーで dedup するため、母艦側データと連結しても
重複は自動排除される (同一局面は先勝ち)。深さ 16 ラベルのため、より浅いラベルと混在させる場合は
`depth` フィールドで層別 (フィルタ/重み付け) 可能。
